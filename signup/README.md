# Как развернуть форму регистрации

Всего два бесплатных сервиса, без своего сервера: **Google Apps Script**
(бэкенд) и **GitHub Pages** (сама страница формы). Оба уже есть у вас, если
вы завели Google-аккаунт и GitHub-репозиторий из основного README.

## Шаг 1. Мастер-таблица + Apps Script

1. Создайте новую Google Таблицу, назовите, например, «Радар — админ».
   Это ваша **административная** таблица — в ней появится лист `Users` со
   списком всех подключённых людей. Только вы должны иметь к ней доступ.
2. Скопируйте её ID из URL — это `ADMIN_SHEET_ID` (понадобится дальше в
   `multi_run.py` и `link_telegram.py`).
3. В этой таблице: **Расширения → Apps Script**.
4. Удалите содержимое по умолчанию, вставьте код из `signup/Code.gs`.
5. Слева — **Свойства проекта (⚙ Project Settings) → Script Properties →
   Add script property**: имя `BOT_USERNAME`, значение — юзернейм вашего
   Telegram-бота без `@` (тот же бот, что и в основном README).
6. Сверху **Deploy → New deployment**:
   - Тип: **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
7. После деплоя скопируйте **Web app URL** — он понадобится в форме.

## Шаг 2. Страница формы

1. В `signup/index.html` замените строку
   `const APPS_SCRIPT_URL = "https://script.google.com/macros/s/ВАШ_DEPLOYMENT_ID/exec";`
   на URL из шага 1.7.
2. Разместите файл где угодно, где отдаётся статика. Проще всего —
   **GitHub Pages**: в репозитории Settings → Pages → Source: ветка `main`,
   папка `/signup`. Через минуту форма будет доступна по адресу вида
   `https://<ваш-юзернейм>.github.io/<репозиторий>/`.
3. Эту ссылку и отправляйте людям, которых подключаете (10-15 человек — как
   обычная ссылка в мессенджере).

## Шаг 3. Проверка

1. Откройте форму, заполните тестовыми данными, отправьте.
2. Должна появиться строка в листе `Users` вашей админ-таблицы.
3. Должна создаться новая личная таблица (проверьте в Google Drive) с доступом
   на указанный e-mail.
4. Должна показаться ссылка на Telegram-бота — перейдите и нажмите Start.

## Что дальше

После заполнения формы человеку нужно **один раз** нажать Start в Telegram —
это единственное ручное действие с его стороны. Дальше `link_telegram.py`
(см. основной README, автоматический запуск по расписанию) подхватит его
`chat_id`, и `multi_run.py` начнёт присылать ему дайджест ежедневно вместе
со всеми остальными.
