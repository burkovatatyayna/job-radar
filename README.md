# 📡 Радар вакансий — как запустить у себя

Ниже — пошагово, без предположения, что вы уже работали с API-ключами.
Всего нужно получить **4 «пропуска»** (секрета) и один раз всё связать.
Дальше система работает сама, раз в сутки.

---

## Что вообще нужно сделать (по шагам)

### Шаг 1. Создать своего Telegram-бота (для доставки дайджеста)

1. В Telegram найдите `@BotFather` (это официальный бот Telegram для создания ботов).
2. Напишите ему `/newbot`, дайте боту имя и юзернейм (любые, например `my_job_radar_bot`).
3. BotFather пришлёт **токен** — длинную строку вида `123456:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.
   Это и есть `TELEGRAM_BOT_TOKEN`. Никому не показывайте.
4. Напишите своему новому боту любое сообщение (например «привет») — боты не могут
   писать первыми, это разовая инициализация.
5. Чтобы узнать `TELEGRAM_CHAT_ID` (это ваш личный ID в Telegram, куда бот будет слать
   дайджест): откройте в браузере
   `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates` (подставьте токен из шага 3),
   там будет `"chat":{"id": 123456789, ...}` — это число и есть ваш `TELEGRAM_CHAT_ID`.

### Шаг 2. Получить ключ OpenAI (для ИИ-оценки вакансий и писем)

1. Зайдите на platform.openai.com, зарегистрируйтесь/войдите.
2. Раздел **API keys** → «Create new secret key».
3. Скопируйте ключ (вида `sk-...`) — это `OPENAI_API_KEY`. Он показывается один раз,
   сохраните сразу.
4. Пополните баланс на пару долларов — на объёме этого проекта (десятки вакансий в день)
   расход в районе центов.

### Шаг 3. Google Таблица + service account (вместо Notion)

Здесь чуть больше шагов, но делается один раз.

1. Создайте новую Google Таблицу (sheets.google.com → «Создать»), любое название,
   например «Радар вакансий».
2. Скопируйте её ID — это часть ссылки:
   `docs.google.com/spreadsheets/d/`**`ВОТ_ЭТО_ID`**`/edit` → это `GOOGLE_SHEET_ID`.
3. Идём в **Google Cloud Console** (console.cloud.google.com):
   - Создайте новый проект (или используйте существующий).
   - В поиске сверху введите «Google Sheets API» → откройте → «Включить» (Enable).
   - Слева меню → **IAM и админ → Служебные аккаунты (Service Accounts)** →
     «Создать служебный аккаунт», любое имя, например `radar-bot`.
   - После создания откройте его → вкладка **Ключи (Keys)** → «Добавить ключ» →
     «Создать новый ключ» → тип **JSON** → скачается файл `xxx.json`.
   - Откройте этот файл текстовым редактором — его **всё содержимое целиком**
     (это и есть `GOOGLE_SERVICE_ACCOUNT_JSON`) нужно будет вставить в GitHub secret
     на шаге 5.
   - В этом же JSON-файле есть поле `"client_email"` вида
     `radar-bot@ваш-проект.iam.gserviceaccount.com` — это e-mail service account'а.
4. Вернитесь в свою Google Таблицу → кнопка **«Настройки доступа»** (Share) →
   вставьте этот e-mail, выдайте права **«Редактор»**.

Без этого шага 4 таблица будет создана, но бот не сможет в неё писать — это
частая ошибка, не пропускайте.

### Шаг 4. Настроить сам проект под себя

Откройте и заполните под себя (это просто текстовые файлы, редактируются в любом
редакторе или прямо на GitHub):

- **`profile.yaml`** — самое важное. Впишите реальное summary о себе, желаемые
  роли, уровень, локации, отраслевые анти-фильтры.
- **`channels.yaml`** — замените примеры на реальные хэндлы Telegram-каналов
  с вакансиями по вашей теме (без `@`, просто `handle`).
- **`hh.yaml`** — впишите реальные `employer_id` целевых компаний (см. в URL
  страницы компании на hh.ru) и заголовки для поиска по рынку.
- **`careers.yaml`** — при желании: карьерные страницы конкретных компаний
  (это не обязательно на старте — можно оставить пустым `companies: []`).
- **`voice.md`** — тон сопроводительных писем, можно оставить как есть или
  переписать под свой стиль.

### Шаг 5. Загрузить секреты в GitHub

1. Создайте новый репозиторий на GitHub, загрузите туда всю папку `radar/`.
2. В репозитории: **Settings → Secrets and variables → Actions → New repository secret**.
3. Добавьте пять секретов (имя точно как ниже, значение — то, что получили выше):
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
   - `OPENAI_API_KEY`
   - `GOOGLE_SERVICE_ACCOUNT_JSON` — вставить **всё содержимое** скачанного JSON-файла целиком
   - `GOOGLE_SHEET_ID`

### Шаг 6. Проверить, что всё работает

1. В репозитории → вкладка **Actions** → workflow «Радар вакансий» →
   **Run workflow** (запуск вручную, не дожидаясь расписания).
2. Смотрите логи каждого шага — если где-то ошибка, там же будет понятная причина
   (неверный токен, нет доступа к таблице и т.п.).
3. Если всё ок — в Telegram придёт сообщение + файл `digest.html`,
   а в Google Таблице появится вкладка «Реестр» с новыми строками.

### Шаг 7. Обучение системы

В Google Таблице у каждой строки — колонки **«Моя оценка» (1–5)** и **«Почему»**.
Заполняйте их руками по мере просмотра вакансий. При следующем запуске
`sheets_sync.py pull` заберёт эти оценки в `feedback.yaml`, и они начнут
использоваться как примеры для ИИ. Обычно нужно 20–30 оценок, чтобы скоринг
«настроился» под вас.

## Локальный тестовый прогон (без GitHub Actions)

```bash
pip install -r requirements.txt

export OPENAI_API_KEY="sk-..."
export TELEGRAM_BOT_TOKEN="..."
export TELEGRAM_CHAT_ID="..."
export GOOGLE_SERVICE_ACCOUNT_JSON="$(cat путь/к/ключу.json)"
export GOOGLE_SHEET_ID="..."

python fetch.py
python fetch_hh_scan.py
python fetch_careers.py
python digest.py
python notify.py
python sheets_sync.py push
python sheets_sync.py pull
```

## Расписание

По умолчанию — 08:00 по Москве (`0 5 * * *` в UTC, файл
`.github/workflows/radar.yml`). Поменяйте под свой часовой пояс, если нужно
(время в cron всегда в UTC).

## Ограничения (честно, как в оригинале)

- Публичный веб-превью Telegram отдаёт последние ~20 постов — для суточного
  окна ок, для более глубокой истории нужен уже официальный Telegram API.
- hh.ru может иногда ограничивать частоту запросов — в коде заложены паузы
  между запросами, специально их обходить не нужно.
- Первые пару недель скоринг будет ошибаться, пока не накопится обратная связь.
